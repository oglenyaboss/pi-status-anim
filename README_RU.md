# pi-status-anim

Анимированная рабочая строка для pi. Пока агент стримит, стандартная строка
статуса заменяется на более насыщенную: стабильный глагол фазы, анимированный
глиф, живой счётчик токенов, индикация зависания и несколько пасхалок. Вся
строка целиком — глаголы, глиф, токены, таймер, пасхалки, stall-фидбек —
живёт здесь.

## Возможности

- **Глаголы по фазам** — глагол меняется только при смене фазы цикла
  (`requesting → thinking → responding`); вызовы инструментов его не трогают.
- **Анимация глифа по фазам** — бегущая точка при запросе, мягкий набор звёзд
  при размышлении/ответе, брайль во время работы инструментов.
- **Счётчик токенов** — полный снимок контента пересчитывается на каждом
  обновлении (никакого накопления), показывается как `↓ 1.2k` с опциональной
  скоростью `· 42/s` и плавным одометром.
- **Stall-фидбек** — нет свежих токенов и активных инструментов 3 секунды:
  глиф плавно краснеет, блик гаснет, в суффиксе появляется слово-стадия
  (worried → desperate → existential). Активный инструмент никогда не даёт
  ложный stall.
- **Liveliness** — скорость и присутствие анимации следуют за реальным
  потоком токенов.
- **Width-gating** — суффиксные части отбрасываются от наименее приоритетных,
  строка никогда не переносится при любой ширине терминала.
- **Подсказка прерывания** — восстанавливается на строке, когда больше
  ничего не показано.
- **Пасхалки** — git-статус, имя модели, время суток, факты после 60 секунд
  размышления, «тревожный градиент» после 60 секунд.
- **Wave / breath** — с `animChance` блик на время цикла заменяется
  бегущей световой волной или спокойным дыханием.
- **reducedMotion** — статичный глиф и обычный текст, один stall-таймер.

## Установка

```bash
pi install <url-репозитория>
```

Никаких runtime-зависимостей: единственный импорт из пакета pi — `import
type` (стирается в рантайме). `/reload` пересоздаёт расширение и заново
читает конфиг; горячей перезагрузки конфига нет.

## Конфигурация

Все опции — в `~/.pi/agent/settings.json`, ключ `statusAnim`. Ниже значения
по умолчанию.

```jsonc
{
  "statusAnim": {
    "enabled": true,
    "words": [],              // дополнительные глаголы к стандартным
    "intervalMs": 50,         // такт текстовой анимации
    "showTimer": true,
    "timerAfterMs": 1000,
    "tokenCounter": true,
    "tokenAfterMs": 3000,     // когда появляются токены (защита от мерцания)
    "tokenRate": true,        // показывать tok/s
    "effortSuffix": "with high effort",
    "stallAfterMs": 3000,
    "stallTiers": true,
    "modelEggs": true,
    "timeEggs": true,
    "gitStatus": true,
    "funFacts": true,
    "anxietyGradient": true,
    "reducedMotion": false,
    "toolDetail": true,       // "(grep · 247 files)", если в args есть счётчик
    "queueHint": true,        // "(+ queued)"
    "phaseGlyphs": true,      // наборы глифов по фазам
    "animChance": 0.25,       // вероятность wave/breath на цикл
    "animAfterMs": 1500,
    "labelActive": "∴ Thinking…",
    "labelDone": "∴ Thinking"
  }
}
```

## Разработка

```bash
npm install          # devDependency (только типы для typecheck)
npm run typecheck    # tsc --noEmit
npm run selfcheck    # проверки чистых модулей (width-gating, FSM, stall)
```

## Примечания

- Текст подсказки прерывания фиксирован (`Ctrl+C`): реестр клавиш pi не
  доступен расширениям, поэтому подсказка не следует за пользовательскими
  биндингами.
- Очередь показывается как `(+ queued)` — API расширений отдаёт только факт
  наличия ожидающих сообщений, без количества.
- Цвета всегда выводятся из токенов активной темы (не захардкожены), включая
  stall-fade, блик, wave/breath и «тревожный градиент».
